# Mi-portafolio
Este repositorio contiene diversos proyectos trabajados en la clase de IA, ML, y mi portafolio

# 🌊 Portafolio Digital

Portafolio personal desarrollado con **Next.js**, **TypeScript** y **Tailwind CSS**, inspirado en una estética marina y diseñado para presentar mis proyectos de algoritmos, análisis de datos e inteligencia artificial, además de mi interés por la física, la investigación científica y la divulgación.

---

##  Características principales

- **Diseño oceánico personalizado:** Portada con composición orgánica, buscador interactivo de proyectos y transición fluida mediante olas SVG.
- **Galería interactiva de evidencias:** Exploración dinámica de proyectos con descripción, enfoque algorítmico, vista ampliada de capturas y descarga de código fuente.
- **Formulario de contacto funcional y seguro:** Implementado con una API Route (`POST /api/contacto`) conectada a **Resend**, con validación de datos, sanitización, protección *honeypot* contra bots y límite de peticiones por IP (*rate limiting*).

---

## Proyectos incluidos

1. **Laberinto (Algoritmos y búsqueda):** Generación de laberintos mediante retroceso con pila y cálculo de ruta óptima con búsqueda en anchura (**BFS**).
2. **AI Challenge – K-Means y KNN (Machine Learning):** Segmentación de datos por similitud mediante aprendizaje no supervisado (**K-Means**) y clasificación supervisada por vecinos cercanos (**KNN**).
3. **Hotspots Comerciales (Análisis y ubicación):** Exploración, filtrado y visualización espacial para identificar zonas de alta concentración comercial.

---

##  Tecnologías utilizadas

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Backend / API:** Next.js Route Handlers, Resend
- **Herramientas:** Git, GitHub, Visual Studio Code, Vercel
